# fixtures/disclosure 来源说明

手工制作的最小联动示例，无外部数据：

* `spec.json`：声明类别 a/b/c，私有计数 a=100、b=20、c=7，受保护类别为 a。
* `request-ab.json`：第一批请求，查询 `{a,b}` 的原始计数和（效用 5）。
  单独公开它不会在有理行空间中确定 `e_a`，安全。
* `request-b.json`：第二批请求，查询 `{b}`（效用 9）。在 `{a,b}` 已公开后，
  `e_a = {a,b} - {b}` 进入公开行空间，必须整体抑制（空集回执）。

`expected/` 为上述两批依次 release 的确定公开回执，逐字节比对用。
